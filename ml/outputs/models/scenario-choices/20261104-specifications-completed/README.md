# 사양 보완 서빙 번들

기반 가중치: `20261103-unified-managed-3m`. **재학습하지 않았다.**
원래 가중치·전처리·특성 정의를 유지하고, 제조사 근거로 검토된 전장 및 좌석의
누락값을 채운 별도 카탈로그를 사용한다. 기존 학습 폴더는 수정하지 않는다.

`metadata.json.catalog_revision`에 근거 manifest와 해시를 기록한다.
`training_report.json`의 학습·홀드아웃 성능은 원래 카탈로그에 대한 지표이며,
보완 이후의 새 품질 측정 결과가 아니다.
`serving_verification.json`은 보완 후 공개 DB 전체 필드 일치, 누락 검사와
실제 추천의 재무·정원 조건 검증 결과다.

공개 381건 모두 전장과 좌석 값이 있다. 검수 대기 3건은 비활성 상태를 유지한다.
DB와 서빙 카탈로그가 다르면 기존 snapshot guard가 계속 요청을 거부한다.
