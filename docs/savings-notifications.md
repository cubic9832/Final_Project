# 드림카 저축 알림

로그인한 회원의 목표 달성과 정기 저축 자동 기록을 헤더 종 아이콘으로 안내한다.

- `GET /api/v1/notifications`: 현재 회원의 알림 목록과 읽음 상태.
- `GET /api/v1/notifications/stream`: Bearer 인증 SSE. ready·changed·heartbeat 이벤트.
- `POST /api/v1/notifications/savings-events`: 본인의 브라우저 저축 기록에서 발생한 이벤트. eventKey를 회원별 고유 키로 처리하므로 재전송해도 중복 생성하지 않는다. 성공은 204.
- `PATCH /api/v1/notifications/{id}`: 본인의 알림을 읽음 처리. 성공은 204, 타인 또는 없는 알림은 404.

SSE에는 인증 토큰을 URL에 넣지 않는다. fetch의 Authorization 헤더를 사용한다. 60초 연결 후 재인증하여 연결하며, 재연결 시 DB 목록을 다시 조회해 누락을 복구한다. 읽음 상태도 다른 접속 탭에 전파한다. V36은 알림 테이블만 추가하며 기존 마이그레이션을 변경하지 않는다.

목표 알림은 계획당 한 번만 생성한다. 기록 삭제로 잔액이 줄었다가 다시 달성해도 반복하지 않는다. 새 정기 기록은 기록 ID별로 한 번씩 알린다. 처음 연결하기 전에 이미 존재한 정기 기록은 과거 알림으로 대량 발송하지 않는다. 수동 저축과 미래 예정 기록은 정기 알림 대상이 아니다.

현재 구매 계획과 저축 원본은 기존 브라우저 저장소를 유지한다. 로그인 중 열린 앱에서 5초 간격·화면 포커스·기록 변경 시 확인한다. 브라우저를 닫은 동안 서버가 계좌 입금을 확인하거나 정기 기록을 생성하는 기능은 없다. 다음 접속 시 예정 기록을 생성하고 알린다. 따라서 정기 알림에는 실제 계좌 입금 확인이 아니라는 안내를 표시한다. 계정의 알림 내역과 읽음 상태는 서버 DB에 보존되지만, 저축 원본의 기기 간 동기화는 제공하지 않는다.

## 삭제와 수신 설정

각 알림의 더 보기 메뉴에서 삭제하거나 해당 유형의 수신을 끌 수 있다. 삭제는 `DELETE /api/v1/notifications/{id}`로 논리 삭제하며 고유 이벤트 키를 남겨 같은 이벤트가 재전송돼도 복구되지 않게 한다. 목록에서 즉시 제외하며 읽지 않은 수에서도 빠진다.

`GET /api/v1/notifications/preferences`와 `PUT /api/v1/notifications/preferences/{type}`(본문 `enabled`)으로 목표 달성·정기 기록 수신을 따로 설정한다. 끈 유형은 새 알림을 생성하지 않는다. 기존 알림과 저축 원본은 유지한다. 알림센터 톱니바퀴에서 다시 켤 수 있다. V37에서 유형·삭제 상태·회원별 수신 설정을 추가한다. 모든 조회와 변경은 로그인한 회원 범위로 제한하며 SSE 변경 이벤트를 통해 다른 탭에도 반영한다.
